Package format

Each package contains independent HTML, CSS and JavaScript, an XML form definition, and XML preview data. The XML definition is checked against the platform XSD. External entities and unsafe archive paths are rejected.

Publishing, GitHub release branches and Docker deployment will be enabled only after the protected release pipeline is configured.
